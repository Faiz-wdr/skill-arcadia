## 🌟 Key Features & Live Plugins

1. **Dual Brand Identity & High-Resolution Logos:**
   - Skill Arcadia signature blue & Grant Thornton purple partnership lockup with glowing divider.
   - Built on transparent, retina-ready assets with enhanced dark-mode contrast.

2. **Live Countdown Timer Plugin (`#countdown-box`):**
   - Live-ticking Days : Hours : Minutes : Seconds counter automatically targeting **September 30 at 6:00 PM IST**.
   - Smooth animated flippers with fallback calculation.

3. **High-Converting Hero Registration Form (`#webinarRegistrationForm`):**
   - **Full Name** (Input with user icon, length validation)
   - **WhatsApp Number** (Split dropdown with international country codes `+91`, `+971`, `+1`, `+44`, `+65`, etc., and mobile regex validation)
   - **Email Address** (With strict email format validation)
   - **Qualification** (B.Com, BBA, CA/CMA Inter & Final, ACCA/CPA, MBA Finance, M.Com, Engineering, etc.)
   - **Current Status** (Final Year Student, Fresh Graduate 0-1 yr, Working Professional 1-3 yrs, Senior 3+ yrs, Career Switcher)
   - **CTA Button**: `[ RESERVE MY SPOT → ]` with shimmer reflection and loading animation.
   - **Trust Assurance**: `Free Registration • Limited Seats* • Instant WhatsApp Pass`

4. **Dynamic VIP Ticket Pass Generator with Confetti (`#ticketModal`):**
   - Triggered automatically upon registration.
   - Canvas Confetti celebratory explosion.
   - Branded digital entry pass displaying attendee name, unique ticket ID (`SA-GT-XXXXXX`), qualification, and status.
   - **Dynamic QR Code** rendered client-side via `qrcode.js` linking to verification.
   - **1-Click WhatsApp VIP Community** join button.
   - **Add to Google Calendar** (auto-fills event title, time, Zoom link, and attendee info).
   - **Download iCal (.ics)** file generation for Apple Calendar and Outlook.
   - **Print / Save Pass as PDF** support.

5. **Live Social Proof Toast Plugin (`#socialProofToast`):**
   - Dynamic real-time notification popups in the bottom-left corner showing recent registrations from Mumbai, Bengaluru, Delhi, Hyderabad, Pune, Dubai, etc.

6. **Live Seat Scarcity Progress Plugin:**
   - Real-time animated progress bar showing "Only 42 seats left out of 500 max capacity".
   - Periodic scarcity updates to encourage prompt registration.

7. **Mobile Sticky Quick-Register Bar (`.mobile-sticky-bar`):**
   - On smartphone viewports, an urgent floating bottom bar stays docked with 1-tap "Reserve Free Spot" jump directly into the form.

8. **Complete Educational & Value Sections:**
   - **Metrics Bar**: 12,500+ Mentored, 90 Mins Masterclass, 85%+ Placement Growth, Big 4 Alumni network.
   - **6 Core Learning Pillars**: Global Finance Shifts, Practical FinTech (Power BI, Modeling), High-Paying Trajectories, Grant Thornton Hiring Secrets, Global Salaries, and Live Q&A.
   - **Who Should Attend**: 4 Audience cards for Commerce Undergrads, CA/CMA/ACCA Candidates, Early Professionals, and Career Switchers.
   - **Keynote Speakers**: Partner profiles from Grant Thornton and Skill Arcadia.
   - **90-Minute Agenda**: Comprehensive chronological schedule breakdown.
   - **Free Attendee Bonuses (Worth ₹15,000+)**: Certificate of Participation, Financial Modeling Excel Kit, Big 4 Interview Guide.
   - **Wall of Love**: Alumni placement reviews and ratings.
   - **Interactive FAQ Accordion**: 6 collapsible answer modules.

## 🚀 How to Run Locally

### Option 1: Direct File Opening
Simply double-click `index.html` or open it in any browser (Chrome, Edge, Firefox, Safari).

### Option 2: Run Local Server (Node.js)
```bash
node server.js
```
Then visit `http://localhost:3000/` in your browser.
